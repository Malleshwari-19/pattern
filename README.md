# Java Pattern Printing Programs

This repository contains basic Java programs to print different star patterns and shapes using nested loops and conditional statements.

##  Programs Included

### 1. Combined Pattern
- Prints a combined star pattern using nested `for` loops.
- Uses spaces and stars to create the pattern.

### 2. Diamond Pattern
- Prints a diamond-shaped star pattern.
- Takes the number of rows as input from the user.
- Uses a `Scanner` for user input.

### 3. Half Pyramid Pattern
- Prints a half-pyramid pattern using stars.
- Uses nested loops to control the rows and columns.

### 4. Outer Layer Matrix Pattern
- Prints a 5 × 5 square border using stars.
- Uses `if` conditions to print stars only on the outer boundary.

### 5. Pattern Printer
- Prints a 5 × 5 star pattern with selected positions containing zeros.
- Uses conditional statements to identify the positions.

### 6. Symmetric Pattern
- Prints a symmetric star pattern using loops and conditional statements.

### 7. X Shape Pattern
- Prints an X-shaped star pattern.
- Uses row and column conditions to position the stars.

##  Technologies Used

- Java
- Nested For Loops
- Conditional Statements
- Scanner Class
- Pattern Printing

##  How to Run

1. Install the Java JDK.
2. Clone or download this repository.
3. Open the project folder in VS Code or any Java IDE.
4. Compile the Java file you want to execute.
5. Run the corresponding class.

Example:

```bash
javac Halfpyramid.java
java Halfpyramid
```

For the other programs, replace `Halfpyramid` with the respective class name.

- Learn row and column-based pattern logic.
